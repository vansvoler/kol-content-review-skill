# 审稿三层弹性标准

> 核心理念：**只有真正危险的内容才一刀切，其余都给达人留创作空间**。
> 达人人设多样，标准化修改意见会被抵触；分层标准让"必改"和"建议"泾渭分明。

## 判定流程

遇到一个问题点，按顺序判断：

```
┌─ 是否触犯广告法/平台硬规则？          → 是 → Tier 1
│
├─ 是否事实性错误（产品/价格/成分）？    → 是 → Tier 1
│
├─ 是否 brief 核心卖点"完全缺失"？      → 是 → Tier 1
│     （不是"表达不同"，是"一个字没提"）
│
├─ 是否偏离 brief 意图但尚可理解？      → 是 → Tier 2
│
├─ 是否影响转化效果（钩子/CTA/互动）？   → 是 → Tier 2
│
├─ 是否纯文笔/节奏/标签优化？           → 是 → Tier 3
│
└─ 上述都不是                          → 不批注
```

**关键判断**：Tier 分级不是"严重程度"，而是"修改强制度"——Tier 1 不改会出事，Tier 2 不改可惜，Tier 3 不改无妨。

## Tier 1 红线（必改，零弹性）

### 1.1 广告法违禁词

- **极限词**：最高级、最佳、最好、第一、唯一、顶级、极致、冠军、NO.1、100%、完美、顶尖
- **功效绝对化**：彻底治愈、永久有效、根治、100%有效、立竿见影
- **医疗暗示**（非医械/药品）：治疗、根除、修复细胞、激活、抗癌、杀菌消炎
- **国家机关背书**：国家级、特供、专供、质检认证（除非有合法授权）
- **迷信词**：开光、辟邪、转运、招财

### 1.2 平台合规违规

- 虚假宣传（未经证实的效果描述）
- 未标注"广告"/"赞助"/"品牌合作"（平台强制要求）
- 医疗功效承诺（美妆/保健品尤其敏感）
- 引导站外交易（跳转私信成交、加微信）
- 诱导分享/集赞（抖音/小红书都限流）

### 1.3 事实性错误

- 产品规格错误（容量、成分、产地、价格）
- 使用方法错误（可能引发用户使用风险）
- 品牌信息错误（品牌名、品牌故事、代言人）
- 价格/优惠信息与 brief 不一致

### 1.4 Brief 核心卖点"完全缺失"

**判定标准**：brief 里明确标注为"必传信息"的卖点，稿件中**完全没有提及**（不是换了说法，是一个字没有）。

**举例**：
- brief 要求"突出成分 A（神经酰胺）"，稿件通篇没出现"神经酰胺"或任何近似表述 → Tier 1
- brief 要求"突出成分 A"，稿件用"屏障修护因子"暗指 → **Tier 2**（表达偏离但在谈同一件事）

## Tier 2 建议（建议改，需理由，中等弹性）

### 2.1 卖点表达偏离 brief

- 核心卖点有提及但被弱化、埋没（如塞在评论区、最后一句）
- 次要卖点挤占核心卖点篇幅
- 卖点被达人个人叙事覆盖（"我用了…很好"但没说为什么好）

### 2.2 品牌调性偏差

- brief 定位高端调性，稿件写成平价安利
- brief 要求专业严谨，稿件过度口语化（但达人人设就是口语化 → 降级 Tier 3 或不批）
- 品牌名出现次数不足/过多

### 2.3 开头钩子与 CTA

- 小红书笔记前 15 字未触及痛点/利益点
- 短视频前 3 秒未勾住观众
- 结尾无引导行动（下单/收藏/关注）或 CTA 与 brief 目标错位

### 2.4 互动引导缺失

- 无提问/争议点引发评论
- 无"戳这里"、"扣 1"等触发动作
- 图文缺少"收藏关键词"（"姐妹们快存起来！"这类）

---

## Tier 3 参考（可保留，高弹性）

### 3.1 文笔与节奏

- 句子冗长可精简
- 段落结构可调整
- 用词可更生动/更简洁

### 3.2 话题标签

- 可补充热门话题标签扩大曝光
- 可替换更精准的垂直标签
- 可增加长尾标签（小众但转化高）

### 3.3 结构微调

- 图文顺序可优化（首图重要性）
- 视频分镜节奏可调整
- 信息密度可分布更均匀

## 四条铁律

所有批注都必须遵守：

### 铁律 1：每条必须说 "why"

不只告诉达人"改成什么"，更要说"为什么"。

| 类别 | Why 模板 |
|---|---|
| Tier 1 合规 | "XX 词违反广告法 X 条 / 小红书 X 规则，会被限流或处罚" |
| Tier 1 事实 | "产品规格错误，正确为 XX，错误信息会误导消费者" |
| Tier 2 Brief | "Brief 要求突出 X 卖点，当前稿件 Y 弱化了此点" |
| Tier 2 效果 | "前 3 秒完读率是小红书核心指标，当前开头 XX 未触达痛点" |
| Tier 3 参考 | "XX 表达更符合目标人群口语习惯" |

### 铁律 2：尊重达人标志性表达

如果某段批注会**破坏达人的个人标签/口头禅/人设**，必须：
1. 降级到更低 Tier（Tier 2 → Tier 3）
2. 或直接不批注，在报告备注"已尊重达人风格保留"

**例子**：
- 达人 A 以"姐妹们"开场是标志性口头禅 → 即使 brief 要求"更专业调性"，也不应强改
- 达人 B 惯用"绝绝子"等网感表达 → 品牌即使偏爱标准用语，也只能建议不能强改

### 铁律 3：提供"替代选项"而非命令改法

Tier 1/2 所有批注必须给 **≥2 个替代方向**（完全相同场景下）或至少 1 个具体改法：

- ❌ 差批注："这里不行，改一下"
- ❌ 差批注："改成『效果很好』"（命令式单一方案）
- ✅ 好批注："『最佳』违反广告法极限词。替代：『体验理想』或『效果出色』"

### 铁律 4：措辞分级

不同 Tier 用不同措辞，避免"看起来都差不多"导致达人失去优先级判断：

| Tier | 批注措辞 | 语气 |
|---|---|---|
| Tier 1 | "必须" / "需" | 不容商量 |
| Tier 2 | "建议" / "考虑" + 理由 | 协商性 |
| Tier 3 | "可参考" / "可选" | 纯提示 |

## 判定边界：易混淆场景

### 场景 1：达人用"暗示"而非"明说"规避违禁词

- 直写"最有效" → Tier 1（极限词）
- 写"懂的都懂，你们 get 到点了吧" → **Tier 2**（虽然暗示但未直接违规，建议改为更稳妥表达）
- 写"我自己用下来很满意" → **无需批注**（主观体验允许）

### 场景 2：Brief 与达人风格冲突

- Brief 要求"突出科技感"，达人是美食博主调性
  - 如果 brief 是硬性要求 → Tier 2（建议融合，给方向）
  - 如果 brief 只是参考 → Tier 3（可参考品牌素材中的科技元素）
  - **绝不 Tier 1**（brief 意图不匹配 ≠ brief 缺失）

### 场景 3：小红书/抖音灰色地带词

- "修复" "改善" "缓解" 单独使用 → 多数情况可用
- 搭配医疗场景 → Tier 1（"修复肌肤屏障"在美妆中常见，但"修复发炎"涉医）
- 判定需看上下文 → 详见 `compliance-words.md` 灰名单

### 场景 4：单字"最"与自然语言

- "最佳/最高级/全网第一"等明确绝对化表达 → Tier 1
- "最近/最初/最终/最爱用的一支"等叙事、时间或个人偏好表达 → 不机械判为 Tier 1
- 判断标准：是否在商品宣传中形成可验证的绝对优势承诺

### 场景 5：产品信息"表达方式不同"

- Brief 写"50ml 装"，稿件写"小瓶装轻巧便携" → **不批注**（没有信息错误）
- Brief 写"50ml 装"，稿件写"100ml 大容量" → Tier 1（事实错误）
- Brief 写"50ml 装"，稿件没提容量 → Tier 2（Brief 要求信息缺失，但非核心卖点）
