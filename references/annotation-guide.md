# 批注指南

> 批注是审稿的"手术刀"——切得精准、切得克制，达人才会真心接受修改。
> 本指南定义批注的**格式规范**、**好坏对照**、**尊重达人人设的边界**。

## 批注格式规范

所有批注使用 Markdown 引用块（`>`），统一三种标签：

### Tier 1 - 必改

```
> [必改] <位置定位>「<原文片段>」
  问题：<具体违规/错误点>
  原因：<广告法第 X 条 / 平台规则 / 事实核查>
  替代：<方向 A> / <方向 B>
```

### Tier 2 - 建议

```
> [建议] <位置定位>
  问题：<偏离 brief / 影响转化>
  理由：<为什么这是问题，基于什么逻辑>
  方向 A：<替代方案 1>
  方向 B：<替代方案 2>
```

### Tier 3 - 参考

```
> [参考] <位置定位>
  <一句话优化建议>
  <可保留原文，仅供参考>
```

## 好坏批注对照

### 场景 A：极限词违规

| | 批注内容 |
|---|---|
| ❌ 差 | "最佳 这个词不行，改一下" |
| ❌ 差 | "改成『效果很好』" |
| ✅ 好 | `> [必改] 第 2 段「效果最佳」`<br>  问题：极限词违反广告法第 9 条<br>  原因：小红书会判定为违规广告并限流<br>  替代：「体验理想」/「效果出色」/「口碑不错」|

### 场景 B：开头钩子弱

| | 批注内容 |
|---|---|
| ❌ 差 | "开头不行，重写" |
| ❌ 差 | "改成：姐妹们！超强安利！" |
| ✅ 好 | `> [建议] 笔记开头首句「我买了这款产品」`<br>  问题：前 15 字未触达痛点/利益点<br>  理由：小红书首屏决定 60% 完读率，开头需快速锁定目标人群<br>  方向 A：痛点式——「一到换季就爆痘的姐妹有救了」<br>  方向 B：反差式——「我以为贵的才好用，直到试了这个 79 元的…」|

### 场景 C：话题标签不足

| | 批注内容 |
|---|---|
| ❌ 差 | "多加点标签" |
| ✅ 好 | `> [参考] 结尾话题标签`<br>  当前仅 2 个大词，可补充 1-2 个长尾词扩大曝光<br>  可选：#敏感肌护理 / #油皮护肤 / #换季护肤|

### 场景 D：卖点缺失 vs 表达不同（关键区分）

**brief 要求**：突出"神经酰胺"成分

**稿件 A 写法**："含有屏障修护因子，能加强肌肤防御力"
- ✅ 批注（Tier 2）：`> [建议] 产品成分描述位置`<br>  问题：brief 要求明确突出「神经酰胺」作为卖点词<br>  理由：品牌长线传播需锚定成分关键词记忆<br>  方向 A：直接说出「神经酰胺」并解释其作用<br>  方向 B：保留当前描述但补充「（关键成分：神经酰胺）」

**稿件 B 写法**：通篇没有提及任何成分
- ✅ 批注（Tier 1）：`> [必改] 产品介绍段落`<br>  问题：Brief 必传信息「神经酰胺成分」完全未出现<br>  原因：这是本次合作核心卖点，达人稿件必须覆盖<br>  替代：建议在正文第 2 段插入成分介绍，至少提及一次「神经酰胺」

## 尊重达人人设的判定流程

批注前先问自己：**这条批注会破坏达人的个人风格吗？**

```
发现问题点
   ↓
是否 Tier 1 红线？ ─── 是 ──→ 必须批注（即使与人设冲突）
   ↓ 否
是否是达人标志性表达？── 是 ──→ 降级判定：
   ↓ 否                         ├─ 原 Tier 2 → 降为 Tier 3
批注保留原 Tier                  ├─ 原 Tier 3 → 不批注
                                 └─ 报告备注「已尊重达人风格保留」
```

### "达人标志性表达"识别

以下属于达人人设的一部分，不轻易修改：

1. **口头禅**：如"姐妹们""老铁们""家人们""绝绝子"
2. **开场习惯**：如固定的打招呼方式、自我介绍
3. **用词偏好**：如某达人喜欢用叠词、emoji、颜文字
4. **叙事风格**：如第一人称故事体 vs 条列测评体
5. **情绪风格**：如高能型 vs 温柔型 vs 理性型

### 灰色场景处理

- brief 要求"专业调性"，达人是标志性口语化风格
  → 不强改开场语气，**建议**在内容中穿插专业术语即可

- brief 要求"情绪共鸣"，达人是理性测评风格
  → 不强改为感性文字，**建议**在结尾加一句用户视角的感受即可

- brief 要求"家庭场景"，达人是单身独居人设
  → 不要求造假场景，**建议**延展为"送家人/给父母"等合理切入角度

## 位置定位技巧

批注要让达人**一眼找到在说哪里**。定位方式按精度递减：

1. **引用原文片段**（最精确）：`「效果最佳，用了都说好」`
2. **段落编号**：`第 2 段` / `第 3 段第 2 句`
3. **结构位置**：`开头首句` / `结尾 CTA` / `话题标签区`
4. **场景描述**：`产品展示镜头口播` / `对比测评部分`

**短视频脚本特殊定位**：
- `分镜 1 口播` / `第 5 秒画面`
- `开头 3 秒钩子` / `结尾引导`

## 结构化批注模板

### 用于 docx/markdown 正文

在原稿 markdown 上**紧邻问题段落后方**插入批注块：

```markdown
## 正文

最近发现一款超好用的洁面，效果最佳，敏感肌必入！

> [必改] 第 1 段「效果最佳」
  问题：极限词违反广告法
  原因：小红书会判定违规并限流
  替代：「口碑很不错」/「自用体验理想」

含有氨基酸温和配方...
```

### 用于 xlsx 脚本表格

在原表格下方追加批注列，或在报告段落中集中列出：

```markdown
## 短视频脚本

| 镜头 | 画面 | 口播 |
|---|---|---|
| 1 | 达人特写 | 姐妹们！这款第一神器必须推！ |
| 2 | 产品展示 | 成分纯天然，效果立竿见影 |

### 批注

> [必改] 镜头 1 口播「第一神器」
  问题：极限词
  替代：「人气好物」/「爆款推荐」

> [必改] 镜头 2 口播「纯天然 + 立竿见影」
  问题：「纯天然」极限化 + 「立竿见影」效果绝对化
  原因：广告法 + 平台双重违规
  替代：「精选植萃配方，使用体验舒适」
```

## 批注密度控制

- **单篇笔记正常密度**：Tier 1 ≤ 3 条，Tier 2 ≤ 5 条，Tier 3 ≤ 3 条
- 超过此密度建议打回重写而非逐条批注
- 通过审核的稿件可零批注，直接在报告里写"内容符合要求"
- Tier 3 可合并（如多个标签建议并为一条）

**批注太多会传递两个错误信号**：
1. "你们是不是不信任我的能力？" → 破坏合作关系
2. "这么多问题我懒得改了" → 达人摆烂

所以**严格控制批注数量**，只打真正重要的点。
